从微信记录到蒸馏自己：蒸馏工作流全教程

1. Target

本文是关于从MAC/Windows电脑上通过各种使用痕迹（尤其是微信）蒸馏出自己完整人格/习惯的教程

你可以直接让claude code读这个网页链接，让它告诉你该怎么一步步操作，包括后续如果遇到问题也可以问claude code

2. Process

其中微信提取聊天记录这部分网上的相关工具基本上已经下架（🐧的法务你是知道的）

需要用到的工具包括：

  1. claude code / codex等本地Agent工具

  2. 用于提取微信聊天记录的工具：

    1. weflow未删减版：用于获取密钥（这个网盘中有对应教程，这个网盘随时可能会删）

      点击链接：https://pan.baidu.com/s/1UUr-w-a2taGbQKDDon0hzQ
      提取码：sqhh

      这一步如果顺利是可以拿到聊天记录的，就不用考虑2.2这一步了；如果在最后一步有问题，记得把提取出来的密钥保存下来，后续2.2 有用

      另外网上也有其他教程，可以自己探索下如何拿到密钥

    2. https://github.com/Roger-Lv/wechat-extract-skill 我自己弄的skill，git glone下来后用上一步拿到的密钥把聊天记录提取出来即可

  3. 用于将聊天记录蒸馏自己的skill

    1. 蒸馏别人：https://github.com/alchaincyf/nuwa-skill
    2. 蒸馏自己：https://github.com/notdog1998/yourself-skill
    3. 蒸馏前任（如果你有的话）：https://github.com/therealXiaomanChu/ex-skill

按照顺序使用即可蒸馏出任何人了。

在给agent提示词的时候，除开聊天记录外尽可能给他额外的足够多的信息，包括你跟其他ai提取出关于自己的信息，你的行程安排，offer，学籍等。
