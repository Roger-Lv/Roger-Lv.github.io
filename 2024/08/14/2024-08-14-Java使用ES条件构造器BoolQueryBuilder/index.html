2. 条件构造

两个过滤条件和一个加分条件怎样组合？ · 分步图解
  1. 候选集合 · 文档 A、B、C。设 A、B 属于同一租户，C 属于另一个租户。
  2. filter · 保留 A、B。先限定可见租户，过滤条件决定入选资格，并不为匹配加分。
  3. must · 只保留匹配项。再要求标题匹配查询词，假设 A、B 均满足。
  4. should · A 获额外匹配。在此有 must/filter 且未额外要求 minimum_should_match 的例子里，should 可影响排序而不强制命中。
  • must可用filter代替，查询效率会更高，因为must会对结果进行_score评估
